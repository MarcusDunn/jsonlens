# JSONPath Compliance Test Suite

`cts.json` is a copy of the JSONPath Compliance Test Suite:
<https://github.com/jsonpath-standard/jsonpath-compliance-test-suite>, commit
`9d1a415a53f5dfb291bc874823892e49174e38eb`.

The BSD-2 license in `LICENSE` applies to `cts.json`.

The parser tests use the `selector` and `invalid_selector` fields. The evaluator tests use all
fields. To update the suite, replace `cts.json` and change the commit above.
